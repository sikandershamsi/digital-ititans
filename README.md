# iTitans Digital Website

Marketing website for **iTitans Digital** — a Frisco, Texas performance marketing and AI automation agency.

Built with Next.js, TypeScript, and Tailwind CSS. Content sourced from iTitans Digital service, about, pricing, and legal documents.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Homepage
- `/about` — About & leadership
- `/services` — Services index
- `/services/[slug]` — Individual service pages
- `/pricing` — Transparent packages
- `/contact` — Contact form
- `/privacy-policy` — Privacy Policy
- `/terms-and-conditions` — Terms & Conditions
